# Empirical case-study artifacts

This directory contains the curated figures and summary tables used in the empirical
case study. The raw vendor data cannot be redistributed, so these artifacts are not
presented as exactly reproducible from a fresh public download.

Fresh runs write to `results/reproduced/`. Their tables, figures, and metadata are
produced by the current pipeline. Exact runs can be compared through the
`data_sha256` value in `run_metadata.json`.
