# Empirical case-study artifacts

This directory contains the curated figures and summary tables from the archived
two-signal case study. It uses current S&P 500 constituents and therefore contains
survivorship bias. The raw vendor data cannot be redistributed, so these artifacts
are not presented as exactly reproducible from a fresh public download or as output
from the current four-signal specification.

Fresh runs write to `results/reproduced/`. Their tables, figures, and metadata are
produced by the current pipeline. Exact runs can be compared through the
`data_sha256` value in `run_metadata.json`.
